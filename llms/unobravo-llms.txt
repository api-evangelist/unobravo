# Unobravo

> Unobravo is an Italian online psychology platform that matches people with licensed psychologists and psychotherapists for individual, couples, and business (B2B wellbeing) therapy delivered through its web app and mobile apps. It operates Italian, Spanish, and French language sites and serves Italians abroad. Unobravo does not publish a public developer API: its backend (api.unobravo.com, AWS API Gateway) is private, and its GitHub organization contains only infrastructure tooling.
